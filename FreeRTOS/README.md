# FreeRTOS 理论笔记 · 深入原理版

围绕内核机制、因果关系和边界条件整理的纯理论笔记，以 FreeRTOS V10.4.6、单核 STM32F103 / Cortex-M3 为主要背景，不含程序代码。

## 阅读入口

- [在 GitHub 上阅读完整笔记](FreeRTOS理论笔记.md)
- [离线 HTML 阅读版](FreeRTOS-theory.html)：下载后用浏览器打开，提供章节目录、窄屏排版和打印样式。GitHub 文件页默认显示 HTML 源文件，不会直接运行阅读页面。

## 内容

20 章依次涵盖基础知识、系统配置、任务创建和删除、任务挂起与恢复、中断管理、临界段保护、调度器挂起与恢复、列表和列表项、任务调度、时间片轮询、任务观测、时间管理、消息队列、信号量与互斥量、队列集、事件标志组、任务通知、软件定时器、Tickless 低功耗和内存管理。

全文约 2.4 万汉字，附 14 张对比表、20 个推演问题与参考判断，以及机制选型和跨章节推演。

## 来源与范围

章节框架参考 [xrbin / FreeRTOS_learning](https://gitee.com/xrbin/FreeRTOS_learning/tree/master/FreeRTOS10.4.6/01-笔记)，正文重新组织撰写。版本相关关键行为核对了该仓库所附 V10.4.6 内核，并参考 FreeRTOS 官方资料。详细来源、版本限制与核对说明见笔记末尾。
