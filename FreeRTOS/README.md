# FreeRTOS 理论笔记

这份个人学习笔记重点解释内核机制、因果关系和边界条件，以 FreeRTOS V10.4.6、单核 STM32F103 / Cortex-M3 为主要背景，全文只讲理论概念。

[阅读完整笔记](FreeRTOS理论笔记.md)

## 内容框架

1. 基础知识：任务与调度的整体模型
2. 系统配置：决定内核行为的规则
3. 任务创建和删除：执行现场的建立与回收
4. 任务挂起与恢复：控制运行资格
5. 中断管理：硬件执行与内核规则的边界
6. 临界段保护：维护不可分割的状态变化
7. 调度器挂起与恢复：推迟调度而保留中断响应
8. 列表和列表项：内核如何组织任务
9. 任务调度：从选择任务到恢复执行
10. 时间片轮询：同优先级任务如何轮换
11. 任务观测：状态、优先级、栈与运行时间
12. 时间管理：延时、周期与超时
13. 消息队列：数据传递与等待机制
14. 信号量与互斥量：同步、资源计数和所有权
15. 队列集：同时等待多个对象
16. 事件标志组：用条件组合组织协作
17. 任务通知：直接作用于任务的通信机制
18. 软件定时器：共享服务任务中的定时处理
19. Tickless 低功耗：在保持时间正确的前提下休眠
20. 内存管理：对象生命周期与分配策略

每章包含推演问题与参考判断，附录整理机制选型、跨章节推演及版本范围。

## 阅读方式

按章节顺序建立整体模型，再沿任务状态、等待关系、保护边界、时间行为和存储生命周期五条线索复习。具体结论应结合正文给出的版本、配置和处理器架构理解。
